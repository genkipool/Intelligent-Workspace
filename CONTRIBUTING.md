## English (Primary)

# Contributing to Intelligent Tab Group (Intelligent Navigator)

We greatly appreciate your contributions! To protect the project's intellectual property and ensure its ongoing development, we ask that you read the following terms before submitting a Pull Request (PR):

## Contributor License Agreement (CLA)

By submitting a Pull Request to this repository, you declare that the contributed code is your original work and you irrevocably, perpetually, and royalty-free assign all intellectual property rights and commercial exploitation rights of that contribution to **GENKI Organization**. This allows us to legally include your improvements in the official extension published on the Chrome Web Store.

If you do not agree to these terms, please do not submit the Pull Request. For accepted contributions, we will proudly include your name in the Acknowledgements / Credits section of the official extension!

## Español

# Guía para Contribuir a Intelligent Tab Group (Intelligent Navigator)

¡Agradecemos mucho tus contribuciones! Para proteger la propiedad intelectual del proyecto y asegurar su desarrollo continuo, te pedimos que leas los siguientes términos antes de enviar un Pull Request (PR):

## Acuerdo de Licencia de Colaborador (CLA)

Al enviar un Pull Request a este repositorio, declaras que el código que aportas es de tu autoría y cedes de forma irrevocable, perpetua y gratuita todos los derechos de propiedad intelectual y explotación comercial de esa contribución a **GENKI Organización**. Esto nos permite incluir legalmente tu mejora en la extensión oficial publicada en la Chrome Web Store.

Si no estás de acuerdo con estos términos, por favor no envíes el Pull Request. Para las contribuciones aceptadas, ¡añadiremos con orgullo tu nombre a la sección de Agradecimientos / Créditos en la extensión oficial!
